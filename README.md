### What is XCutors?

XCutors is a collection and universal loader for various popular Roblox script executors, designed to run Lua scripts on the Windows platform.

### Which Roblox executors are included?

The collection currently supports Volt, Synapse Z, Potassium, and Wave, with the universal xcutorsLoader facilitating easy switching between them.

### Do I need to disable my anticomponent?

Some anticomponent software may flag executor components. It is often recommended to add the XCutors folder to your anticomponent exclusion list or temporarily disable protection while using it.

### Where can I find scripts to run?

XCutors has a built-in community script section. You can also load any standard Lua script file from your computer.

### How do I update XCutors?

Check the GitHub Releases page for new versions. Download the latest package and follow the installation steps again over your existing folder.

### Does it work on other operating systems?

Currently, XCutors is developed exclusively for Windows desktop environments. Support for other platforms is not available.
